# 面试搭子 · MVP（纯前端原型）

粘贴腾讯会议 / 飞书会议链接 → 一键生成「面试搭子匹配页」，按岗位 / 城市 / 时间找同伴连麦互练。

## 当前形态（MVP v1）
- 纯前端、零后端：数据用 base64 编码进 URL `#d=` 片段，不发任何服务器
- 生成页 `index.html`：填会议链接 + 岗位 / 城市 / 时间 / 联系方式 → 产出可分享链接
- 匹配页 `match.html`：读链接片段渲染搭子卡，支持「一键入会」「复制联系方式」
- 微信 UA 检测：在微信内打开时提示「用浏览器打开」（因 .xyz 在微信可能被拦）

## 后续产品版（独立系列，非本期）
- 后端撮合：粘贴链接 → 写入数据库 → 按岗位/城市/时间智能匹配其他搭子
- 账号体系、会话、评价
- 独立域名 / 小程序

## 模块化调用（深链参数）

来源站可用 URL 参数直接调起对应岗位、并带「返回来源」上下文：

| 参数 | 取值 | 作用 |
| --- | --- | --- |
| `?role=` | `辅警` / `消防员` / `公务员` / `教师` / `其他` | 预选岗位下拉框（`消防`→`消防员`、`警察`/`公安`→`辅警` 自动归一） |
| `?from=` | `hub` / `fj` / `xf` | 顶栏显示「返回 RCJ Hub / 辅警站 / 消防站」 |

示例：
- 辅警站入口：`https://<部署域名>/?role=辅警&from=fj`
- 消防站入口：`https://<部署域名>/?role=消防员&from=xf`
- 生成的匹配页会自动带上 `?from=`，同伴点开也能一键回到来源站。
