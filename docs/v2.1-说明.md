# FaceTalk v2.1 面试间

> 状态：**已上线**（无需在 D1 后台手动建表，首次请求自动建）

## 一句话
匹配成功、试音互评通过之后，双方可以在房间里直接开一场 **30 / 45 / 60 分钟的完整面试**：
浏览器原生实时语音 + 边说边转文字拼成对话稿 + 结束用**你自己的大模型 Key** 出结构化点评。

## 为什么这么做
- **不装 App 也能用**：全部功能写在现有网站里，WebRTC 用浏览器原生 API，安卓 APK 只是个 3–4MB 的 WebView 壳，一套代码全平台通吃。
- **不花我的钱**：AI 能力全部走用户自带的 API Key，服务端只做同域转发消除 CORS，**不存 key、不写日志、不落库**。
- **不留数据**：对话稿只在房间存活期间存在，房间一关立即物理删除；WebRTC 信令 10 分钟即弃。

## 功能清单

| 能力 | 说明 |
|---|---|
| 单场计时 | 30 / 45 / 60 分钟三档，倒计时到点自动停录并触发评价 |
| 录音转文字 | 每 20 秒一段增量转写，走 Whisper 兼容接口，转完写回房间，双方同步可见 |
| 实时语音 | 浏览器原生 WebRTC P2P（Google STUN）。直连失败会提示改用腾讯会议链接 |
| 手动记笔记 | 没配 STT 也能用，手打一句回车即入对话稿 |
| AI 结构化点评 | 五维打分（内容切题/逻辑结构/语言表达/岗位匹配度/综合表现）+ 一句话总评 + 3 条改进建议 |

## 用户怎么配

点房间右上角 **⚙** → 填两组接口（**只存在你自己手机/电脑的浏览器里**）：

1. **大模型**（AI 评价）：任意 OpenAI 兼容接口
   - 预设内置 OpenAI / DeepSeek / 通义千问 / Kimi / SiliconFlow
2. **语音转文字**（可选）：Whisper 兼容接口
   - Base / Key 留空则自动复用上面那组，**只有模型名必须单独填**（如 `whisper-1`、`FunAudioLLM/SenseVoiceSmall`）

没配大模型也能正常面试，只是没有自动转录和 AI 点评。

## 技术实现

### 后端（Cloudflare Pages Functions + D1）

- `functions/api/llm.js` —— 同域转发代理
  - `?type=chat` → `{base}/chat/completions`
  - `?type=transcribe` → `{base}/audio/transcriptions`
  - 只允许 **https** base（防内网穿透 / 明文泄露 key）；音频上限 25MB；每 IP 每分钟 20 次
- `functions/api/interview.js` —— 面试间数据通道，轮询 1.5s
  - `interview_lines`：转录行，`who` 用 a/b 标识，前端按 `mine` 渲染
  - `rtc_signals`：offer / answer / ice 中转，只投递给对方
  - **表未建时首次请求自动 `CREATE TABLE IF NOT EXISTS`**（同 2.0 试音的做法）

### 前端

- `assets/settings.js` —— `window.FTSettings`，localStorage 键 `ft_settings_v21`
- `assets/interview.js` —— `window.FTInterview`，计时 / STT / WebRTC / 评价渲染
- `pair.html` —— 面试间卡片放在**试音互评卡之后**，并纳入同一套门禁：互评没通过不给开面试

### 两个容易踩的坑（已处理）

1. **信令游标不能直接推到 max(created)**
   `created` 是秒级，同一秒内会有多条 ICE 候选。若把游标推到最大值，同秒内后到的候选会被 `created > sinceSignal` 永久过滤掉 → 连不通。
   做法：游标回退 2 秒重叠拉取，靠 `seenSig` 按 id 去重。

2. **一方点了语音、另一方没点 → 干等**
   收到 offer 但本方未开启语音时，暂存 `pendingOffer` 并弹出「📞 对方发起了实时语音」提示；本方点接听时直接走应答路径，不再互发 offer（避免 glare 冲突）。

## 安卓壳

`android/` 仍是极简 WebView 壳（约 3–4MB）：
- `versionName 2.1`
- Manifest 增加 `RECORD_AUDIO` / `MODIFY_AUDIO_SETTINGS`
- `WebChromeClient.onPermissionRequest` 放行 `getUserMedia` / WebRTC 麦克风

## 数据清理

`functions/_cleanup.js` 每日定时（GitHub Actions POST `/api/cleanup`）：
- 房间关闭 → `interview_lines` 立即删
- 孤儿行、超过 24 小时的转录行一并清
- `rtc_signals` 超过 10 分钟即删
