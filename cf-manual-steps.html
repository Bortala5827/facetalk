面试搭子 · Cloudflare 手动操作清单

所有 SQL 在 CF 后台 → Pages → mianshi-dazi → D1 → mianshi-dazi-d1 → 控制台 粘贴执行。每块点「复制」即可。ALTER 重复执行报 duplicate column 属正常，忽略；CREATE TABLE IF NOT EXISTS 可重复跑。

必做（本次 6 项修复依赖，不跑则功能不生效）

① 房间自动解散 + IP 在线人数

退出组队 60s 倒计时解散、互评完 5 分钟自动解散、首页「当前在线发需求人数」统计。对应 alter-room-dissolve.sql。

ALTER TABLE pairs ADD COLUMN dissolve_at INTEGER DEFAULT 0; ALTER TABLE pairs ADD COLUMN closed_at INTEGER DEFAULT 0; ALTER TABLE intents ADD COLUMN ip TEXT DEFAULT '';

② 阅后即焚

消息「🔥阅后即焚」勾选后，接收方读取即删。对应 alter-messages-burn.sql。

ALTER TABLE messages ADD COLUMN burn INTEGER DEFAULT 0; ALTER TABLE messages ADD COLUMN read INTEGER DEFAULT 0;

③ 搭子屏蔽表

评价时勾「不再匹配此搭子」写入本表，之后浏览/收件箱过滤被屏蔽的人。对应 schema.sql 内 blocks 段。

CREATE TABLE IF NOT EXISTS blocks ( user_id TEXT NOT NULL, blocked_id TEXT NOT NULL, created INTEGER NOT NULL, PRIMARY KEY (user_id, blocked_id) ); CREATE INDEX IF NOT EXISTS idx_blocks_user ON blocks(user_id);

④ 管理员密码解锁限流（环境变量）

超频（每日 30 次）时弹框输入此密码即可继续。不是 SQL，是 CF 环境变量。

变量名：MS_ADMIN_KEY 变量值：自定义管理员密码（例如 rcj9527admin） 位置：CF Pages → mianshi-dazi → Settings → Environment variables → Production → Add variable

不设则超频时只能等次日重置；设了之后前端弹框输入密码本次会话免再输。

顺带确认（之前功能依赖，没跑过会报错或功能缺）

⑤ 联机信息列（会议号 / 联系方式）

搭子房顶部常驻的腾讯会议号 / 联系方式互看功能依赖这两列。对应 alter-pairs-info.sql。

ALTER TABLE pairs ADD COLUMN info_a TEXT DEFAULT ''; ALTER TABLE pairs ADD COLUMN info_b TEXT DEFAULT '';

⑥ 留言墙表

首页公开留言墙（已上线在用）。若 D1 库是早期建的，可能缺这三张表。对应 wall-tables.sql，可安全重复跑。

CREATE TABLE IF NOT EXISTS wall ( id TEXT PRIMARY KEY, name TEXT, text TEXT, created_at INTEGER ); CREATE INDEX IF NOT EXISTS idx_wall_created ON wall(created_at DESC); CREATE TABLE IF NOT EXISTS wall_rl ( ip TEXT PRIMARY KEY, last_ts INTEGER ); CREATE TABLE IF NOT EXISTS wall_day ( ip TEXT NOT NULL, day TEXT NOT NULL, n INTEGER DEFAULT 0, PRIMARY KEY (ip, day) );

执行完任意 ALTER 后，_functions 代码已 try/catch 兼容，无需重新部署即可生效；若仍报错，去 Deployments 点 Retry 一次。
